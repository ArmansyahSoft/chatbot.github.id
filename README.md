#🏡 Nusantara Properti Ilusrasi AI Chatbot CS

Chatbot Customer Service berbasis AI untuk perusahaan properti premium Indonesia.

#Fitur
- 💬 Chat dengan AI Assistant Properti Yang bernama (Nara)
- 🧮 Simulasi Penghitungan KPR otomatis
- 📅 Form jadwal survei properti
- 📞 Hubungi Customer Service
- 📱 Responsive di semua device

#Teknologi
- HTML, CSS, JavaScript
- Vercel Serverless Function
- Groq AI API (LLaMA 3.3)
- Deployed di Vercel
